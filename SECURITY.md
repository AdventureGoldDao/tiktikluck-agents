# Reporting a problem

If you find a security problem with TikTikLuck, its MCP server or its API, please email
**tiktikluck@bot.cue.im** with what you found and how to see it. Please don't open a public issue for it.

If an API key was shared by mistake, its owner can turn it off at once on TikTikLuck under
**Profile → API key for agents**, and make a new one.

For anything else about these examples, open an issue in this repo.
